# 系统C 使用说明

## 数据库（作业提交格式）

按 `2026作业2路线1提交数据库说明文档.md` 连接 **hw4** 库：

| 项目 | 值 |
|------|-----|
| 主机 | `10.60.254.44:3306` |
| 库名 | `hw4` |
| 用户 | `root` / `123456` |

**提交表**（须含 `group_no`、`dept_no`）：

- `student` — 学生
- `course` — 课程
- `sc` — 选课

系统 C 固定 `dept_no=C`。组号默认 `group_no=3`（可通过环境变量 `GROUP_NO` 覆盖）。

## 安装与启动

```bash
pip install -r requirements.txt
python app.py
```

登录：`admin / 123456`（管理员行写入 `student` 表）

首次使用：「初始化」→ **初始化示例数据**（仅清空本组 `dept_no=C` + `group_no` 的数据）

## 示例数据规模

- 50 名学生（`C20230001`～`C20230050`）
- 10 门课程（`C0000001`～`C0000010`，前 6 门 `share_flag=Y`）
- 每人 5 门选课

## 集成服务器

与改造前相同：XML 接口 `8080`，Internal API `8083`。集成辅助表（`imported_shared_courses` 等）按 `group_no` 隔离，不影响提交的三张主表结构。

## 环境变量（可选）

| 变量 | 默认 | 说明 |
|------|------|------|
| `GROUP_NO` | `3` | 组号 |
| `DB_HOST` | `10.60.254.44` | 数据库主机 |
| `DB_NAME` | `hw4` | 数据库名 |
| `DB_USER` | `root` | 用户名 |
| `DB_PASSWORD` | `123456` | 密码 |
